# Week 3 - Spam Classifier

## Objective

Build a machine learning model to classify text messages as Spam or Ham (Not Spam).

## Concepts Learned

- Text Preprocessing
- TF-IDF (Term Frequency-Inverse Document Frequency)
- Naive Bayes Classification
- Train-Test Split
- Model Evaluation
- Accuracy
  
## Dataset

The project uses an SMS Spam dataset containing messages labeled as either:

- Ham - Normal message
- Spam - Unwanted/promotional message

## Workflow

Raw Text → Text Preprocessing → TF-IDF → Naive Bayes → Spam/Ham Prediction

- `README.md` - Project documentation
- `spam_classifier.ipynb` - Jupyter Notebook containing the complete implementation
